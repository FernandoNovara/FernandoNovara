## 🚀 Proyecto destacado

**Kiosco Antojo** es un proyecto propio orientado a la gestión comercial de un kiosco, con posibilidad de evolución futura hacia un modelo SaaS.

El sistema está pensado para administrar ventas, productos, inventario, caja, estadísticas y configuraciones del negocio.
